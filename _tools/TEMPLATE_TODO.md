# 待框选模板清单（固定坐标 → 模板识别）

> 用法：切到对应页面 → 工具里按 **F5 重新抓帧**（或点「⟳ 重新抓帧」按钮）→ 拖框 → 填下表的名字 → 保存。
> 右侧会显示「负样本最高分」，**低于 0.7 就安全**；0.7~0.8 告诉我，我加 ROI；>0.8 请缩小选框重框。
> 框完一批告诉我，我改 pipeline 并同步到手机。
